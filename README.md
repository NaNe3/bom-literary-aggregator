# Overview

In a sincere attempt to learn how to use the C++ language, I created this project to learn several skills including: file reading, then writing, lists, filtering, and various algorithms. This program opens a file which contains the Book of Mormon, captures every single word, counts how often individual words are used, ranks words by word count, then writes the results to a csv file.

[Super Super Cool Demo Video](https://youtu.be/Iztt7sEvLPI)

# Development Environment

The version of C++ which was implemented in this project is C++ 17

## Libraries Used:
- fstream: read and write files
- algorithm: sorting, searching, counting of arrays
- iostream: basic C++ stuff
- stdexcept: error handling
- string: text operations and manipulation
- vector: dynamic array container for resizeable lists
